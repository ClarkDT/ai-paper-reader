# 📊 阿唐的 AI 论文阅读站

每周一早 9 点，AI 自动从 arXiv 精选 **10 篇论文**，配好中文精读笔记，放进一个单文件阅读器。

**在线阅读（GitHub Pages）**：https://clarkdt.github.io/ai-paper-reader/

**本地阅读**：双击 `index.html` 即可，无需任何服务器或依赖。

## 四大方向（每周按需配比）

| 方向 | 内容 | 为什么读 |
|---|---|---|
| 🏛 经典必读 | 领域奠基论文，慢读精读 | 打地基，读不懂它后面全是空中楼阁 |
| 🤖 Agent 前沿 | 近 1-2 个月 LLM/Agent 新论文 | 跟住前沿，每周更新 |
| 💰 AI + 金融 | LLM 在投研/量化/风险上的应用 | 与金融背景直接衔接 |
| 🔩 AI 芯片算力 | 推理加速、GPU/显存、训练系统 | 建立对算力成本的「防忽悠滤镜」 |

## 每篇论文有什么

- **三分钟看懂**：一句话 TL;DR
- **为什么值得你读**：与读者自身背景的连接点
- **精读笔记**：问题 / 方法 / 结果 / 重要性 / 与阿唐何干
- **关键术语**：中英对照 + 白话解释
- **阅读路径**：30 分钟速读版 / 2 小时精读版
- 功能：已读进度、本机笔记（localStorage）、分类筛选、搜索、可选 AI 提问

## 目录结构

```
05_论文阅读/
├── index.html          # 阅读器（单文件，无外部依赖）
├── data/
│   ├── manifest.js     # 周次清单（阅读器入口）
│   ├── manifest.json
│   └── week-YYYYWnn.js # 每周 10 篇的数据文件
└── weekly/             # 每周 Markdown 消化报告
```

## 每周如何更新

每周一 09:00 由 AI 自动执行：抓取 arXiv 最新论文 → 按 4 方向配比选 10 篇 → 生成
`data/week-*.js` + `data/manifest.js` + `weekly/*.md` → 提交推送本仓库。
笔记基于论文真实摘要撰写，**元数据一律来自 arXiv API 实时抓取，不编造**。

## AI 提问（可选）

阅读器右上角 ⚙️ 填入 OpenAI 兼容接口（如 DashScope compatible-mode）的地址、Key、模型名，
即可在每篇论文下方向 AI 提问。Key 只存本机浏览器，不经过任何第三方。
